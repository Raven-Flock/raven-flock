Work

Labor Pulse — labor companion tool

Time contractions, see the pattern, breathe through the peak, browse positions, and keep a hospital-bag checklist. Logs stay on the device, with no account, and nothing is sent unless the user chooses to share.

What it shows: a tool built for one-handed use under stress, private on-device data, and plain-language limits (not a medical device; timing is a pattern guide, not a diagnosis).

https://raven-flock.github.io/Labor-Pulse/

Stillpoint — meditation web app

Timed sits, box breathing, and a wind-down mode, with an optional soft music bed, in a calm interface.

What it shows: a single-purpose web app with a calm visual design, free to use in any browser.

https://raven-flock.github.io/Meditation-App/
